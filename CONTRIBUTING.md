# Contributing Guidelines

Contributions and improvements to detection logic are welcome.

## Detection Submission Requirements

Every detection should include:

1. Unique detection ID.
2. Clear detection name.
3. Platform and required data sources.
4. KQL or Sigma detection logic.
5. MITRE ATT&CK mapping where applicable.
6. Investigation guidance.
7. False-positive considerations.
8. References.

## Naming Convention

DET-001-Suspicious-PowerShell-Execution.kql

## Quality Guidelines

- Validate queries before submission.
- Use meaningful variable and column names.
- Avoid hardcoded sensitive information.
- Document query limitations.
- Include relevant references.
- Never submit confidential company or customer data.
