# SOC Detection Engineering & Threat Hunting

A continuously maintained cybersecurity repository focused on detection engineering, KQL development, Microsoft Sentinel, Microsoft Defender XDR, and proactive threat hunting.

## Objectives

- Develop custom KQL detection rules.
- Build Microsoft Sentinel analytics and hunting queries.
- Develop Microsoft Defender XDR Advanced Hunting queries.
- Investigate endpoint, identity, email, network, and cloud threats.
- Map detection logic to MITRE ATT&CK.
- Document investigation procedures and false-positive considerations.

## Repository Structure

| Directory | Purpose |

| Microsoft-Defender-Identity | Identity threat detections |

## Detection Documentation

Each detection should include:

- Detection ID and name
- Platform and data source
- Severity and MITRE ATT&CK mapping
- Detection logic
- Investigation guidance
- False-positive considerations
- References and change history

## Disclaimer

This repository is intended for defensive cybersecurity research, threat detection, threat hunting, and educational purposes. All queries must be validated in an authorized environment before production deployment.
